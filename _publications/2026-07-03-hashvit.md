HashViT introduces a dedicated HASH token that evolves throughout a Vision Transformer. The token contains a register for binary codes and a workspace for continuous semantic information, with a refinement adapter connecting the two. This design brings hash learning into the backbone to reduce the discrepancy between learned features and retrieval codes.
